# 📸 Smart Image Resizer - 스마트 사진 편집 & 리사이저 웹 앱

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Platform: Web](https://img.shields.io/badge/Platform-Web%20Browser-success.svg)](#)
[![Built with: HTML5 Canvas](https://img.shields.io/badge/Built%20with-HTML5%20Canvas%20%26%20JSZip-indigo.svg)](#)

> 서버 전송 없이 100% 브라우저 내에서 안전하게 사진을 다양한 표준 비율(1:1, 3:4, 4:3, 9:16, 16:9, 커스텀)로 리사이즈하고, **여백 채우기(Padding, 투명 PNG/흰색 JPG)** 또는 **크롭(Crop)** 방식으로 변환하여 개별 및 전체 ZIP 일괄 다운로드하는 웹 애플리케이션입니다.

---

## ✨ 핵심 기능 (Features)

1. **상단 로고 및 나나랩 링크**
   - 상단 좌측 `logo.png` 클릭 시 새 창에서 `https://nanalab.kr`로 이동합니다.
2. **다양한 업로드 방식**
   - 📂 파일 선택 대화상자 다중 업로드
   - 🖱️ 브라우저 드래그 앤 드롭 업로드
   - 📋 **클립보드 즉시 붙여넣기 (`Ctrl + V`) 지원** (화면 캡처 후 붙여넣기 즉시 인식)
3. **2가지 리사이즈 모드 지원 (화면 비율 vs 실제 규격 치수)**
   - 📐 **화면 비율 모드**: 1:1 (인스타), 3:4 (증명), 4:3, 9:16 (쇼츠/릴스), 16:9 (유튜브), 커스텀 W:H
   - 📏 **실제 치수 모드 (신규)**: `mm`, `cm`, `inch`, `px` 단위 지원 및 `300 DPI / 150 DPI / 72 DPI` 고품질 인쇄 해상도 연동
     - 🪪 여권 사진 (35×45mm @ 300DPI)
     - 📄 반명함/이력서 (30×40mm @ 300DPI)
     - 💳 명함 (90×50mm @ 300DPI)
     - 🖼️ 4×6 인화 (4×6inch @ 300DPI)
     - 🖥️ 웹 FHD (1920×1080px)
4. **리사이징 맞춤 방식 (Fit Mode)**
   - **Padding (여백 채우기)**: 사진이 잘리지 않도록 100% 원본을 보존하며 남는 공간에 여백을 채웁니다.
     - 🎨 **여백 색상 커스텀**: 흰색, 검은색, 라이트그레이, 네이비, 핑크, 하늘색, **투명 알파(Transparent)** 지원
     - 🖼️ **포맷 자동 변환**: 투명 여백 선택 시 자동으로 `.png`로 변환되어 투명도가 보존됩니다!
   - **Crop (비율 맞춰 자르기)**: 여백 없이 캔버스를 꽉 채우며 중앙을 기준으로 가장자리를 깔끔하게 잘라냅니다.
5. **🎯 스마트 압축 & 목표 용량(KB) 자동 맞춤 엔진 (신규)**
   - **스마트 화질 압축**: 20% ~ 100% 품질 슬라이더로 파일 크기를 조절하여 수십 KB 수준까지 경량화
   - **목표 용량 이하 맞춤 (이진 탐색 알고리즘)**: `100KB`, `200KB`, `300KB`, `500KB`, `1MB` 또는 직접 입력한 용량을 **절대 초과하지 않도록 최상의 화질을 자동 탐색하여 100% 맞춤 보장** (공공기관, 이력서, 시험 접수 필수 기능)
6. **90° 좌/우 회전 버튼**
   - 스마트폰으로 촬영하여 누워있는 사진도 카드 내의 `⟲ 90° 좌회전`, `⟳ 90° 우회전` 버튼으로 즉시 바로잡을 수 있습니다.
7. **대형 고해상도 미리보기 모달 (Zoom Modal)**
   - 카드 목록의 썸네일을 클릭하면 대형 팝업 창에서 여백 및 크롭 처리된 최종 결과물을 고화질로 확인하고 바로 다운로드할 수 있습니다.
8. **실시간 프로그레스 바 & 개별 다운로드**
   - 각 사진별로 작업 진행률이 0% → 100%로 부드럽게 차오르며, 완료 시 다운로드 버튼이 활성화됩니다.
9. **전체 ZIP 일괄 다운로드**
   - 모든 사진 작업이 완료되면 상단 `전체 ZIP 일괄 다운로드` 버튼이 켜지며, 클릭 시 `resized_images.zip` 압축 파일로 한 번에 다운로드됩니다.

## 🌐 GitHub Pages로 무료 웹 호스팅하는 방법

이 프로젝트는 백엔드 서버 없이 100% 클라이언트 정적 파일로 동작하므로, GitHub Pages를 통해 무료로 전 세계에 배포할 수 있습니다:

1. 이 `photo_Resizer` 폴더의 파일들을 GitHub 새 저장소(예: `photo-resizer`)에 업로드(Push)합니다.
2. GitHub 저장소 상단의 **Settings** ➡️ 좌측 메뉴의 **Pages** 클릭.
3. **Build and deployment** 항목에서:
   - Source: `Deploy from a branch` 선택
   - Branch: `main` (또는 `master`) / `/ (root)` 선택 후 **Save** 클릭.
4. 약 1분 후 발급되는 주소(`https://<아이디>.github.io/<저장소명>/`)로 누구나 웹에서 바로 사용할 수 있습니다!
